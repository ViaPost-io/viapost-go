# Security Policy

## Supported versions

Security fixes are provided for the latest `0.1.x` release while the SDK is pre-1.0. Upgrade to
the most recent patch before reporting a problem.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting:

<https://github.com/ViaPost-io/viapost-go/security/advisories/new>

Do not open a public issue and do not include live API keys, customer data, or production payloads.
Include the affected SDK version, impact, reproduction steps using synthetic data, and any proposed
mitigation. The ViaPost team will acknowledge the report and coordinate disclosure privately.

API keys must be stored only in server-side secret management and rotated immediately if exposed.
